# 👥 Customer Churn Prediction using Machine Learning

## 📌 Project Overview
This project predicts whether a customer is likely to leave a company (churn) based on customer information and purchasing behavior.

## 🎯 Problem Statement
Companies want to identify customers who may stop using their services. This Machine Learning model helps predict customer churn and improve customer retention strategies.

## 📂 Dataset
Dataset contains customer information:

Features:
- Age
- Total Purchase
- Account Manager
- Years with Company
- Number of Sites
- Location
- Company

Target:
- Churn (0 = Customer Stayed, 1 = Customer Left)

## 🤖 Machine Learning Model
- Random Forest Classifier

## 📊 Evaluation Metrics
- Accuracy Score
- Classification Report
- Confusion Matrix
## 📌 Conclusion
The model predicts customer churn effectively and helps businesses identify customers who are at risk of leaving.
